## Cutting-Edge Web Platform Stack (Chrome 155+ & Mobile WebGL)

- **Mobile-First 3D WebGL Telemetry Engine (`assets/js/network.js`)**:
  - Continuous autonomous 3D orbital rotation and sine-wave depth undulation so the 3D background is always moving on mobile phones without requiring a mouse cursor.
  - Reacts to **mobile touch-drag / swipes**, **tap shockwaves**, **scroll-linked 3D flight**, and **device gyroscope tilt (`deviceorientation`)**.
  - Live interactive geometry & shader mode switching (`01 · MESH`, `02 · VORTEX`, `03 · STREAM`).
- **Chrome 155+ Modern CSS (`assets/css/style.css`)**:
  - **CSS Houdini `@property` (`--laser-angle`)**: Hardware-accelerated rotating conic-gradient laser borders on every card and monogram badge.
  - **CSS Scroll-Driven Animations (`animation-timeline: scroll(root)` & `animation-timeline: view()`)**: Native scroll laser progress bar and 3D perspective card entry transforms without main-thread scroll jank.
  - **Wide-Gamut `oklch()` & `color-mix(in oklch, ...)`**: High-contrast OLED color system.
  - **Native CSS Nesting, `@starting-style`, `interpolate-size: allow-keywords`, and `<dialog>` Popover Modal**.
- **Custom Animated Vector Schematics (`assets/img/`)**:
  - `systems-core.svg` — Interactive multi-ring Central Intelligence reactor core.
  - `venture-nutravit.svg` — Animated WooCommerce + n8n + AI Agent pipeline schematic.
  - `venture-pcin.svg` — Animated hardware diagnostic waveform & NocoBase ERP schematic.
  - `venture-vareautomater.svg` — Animated smart vending fleet telemetry schematic.
- **Mobile Thumb-Zone OS Dock**:
  - App-like floating glass dock pinned to the mobile thumb zone (`HUD`, `Ventures`, `Core OS`, `Stack`, `Cmd`).
