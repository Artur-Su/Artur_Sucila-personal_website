# Artur Sucila — Personal Website & Executive Portfolio

Live site: **[artur-su.github.io/Artur_Sucila-personal_website](https://artur-su.github.io/Artur_Sucila-personal_website/)**

Executive profile and systems architecture portfolio for **Artur Sucila** — Systems Builder, Strategist, and Multi-Venture Operator based in Norway.

## Architecture & Technologies

Designed for fast, zero-dependency static hosting on **GitHub Pages**:

- **Modular Asset Structure**:
  - `index.html` — Primary executive overview, venture portfolio, systems architecture, capabilities matrix, and contact channels.
  - `news.html` — Announcements, recruitment, and active community initiatives.
  - `assets/css/style.css` — Modern CSS architecture utilizing CSS Custom Properties, CSS Grid, fluid `clamp()` typography, multi-page `@view-transition`, and glassmorphic spotlight surfaces.
  - `assets/js/main.js` — Native ES Module (`type="module"`) powering the `⌘K` / `Ctrl+K` Command Palette, active section scroll-spy, interactive card spotlight tracking, one-click email copy, and a live Oslo (`Europe/Oslo`) timezone clock.
  - `assets/js/network.js` — Hardware-accelerated Three.js WebGL particle/node network with automatic `prefers-reduced-motion` support and background tab pause (`visibilitychange`) for optimal battery and GPU efficiency.
  - `favicon.svg` — Custom geometric vector monogram (`AS.`).
  - `.nojekyll` — Bypasses legacy Jekyll processing on GitHub Pages for direct, instant static asset serving.
- **SEO & Semantic Web**:
  - Embedded `Schema.org` (`Person` & `Organization`) JSON-LD structured data and OpenGraph metadata.
